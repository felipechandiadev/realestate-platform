# 13 · Glosario

| Término | Significado |
|---|---|
| **API / core** | Servicio central que guarda datos y aplica reglas de negocio |
| **Backoffice** | Panel interno para administradores y agentes |
| **CMS** | Módulo para editar el contenido del portal sin programar |
| **CLP / UF** | Peso chileno / Unidad de Fomento (unidad reajustable) |
| **Comunidad** | Clientes registrados en el portal |
| **CI** | Integración continua: verificaciones automáticas en cada cambio de código |
| **Destacada** | Propiedad mostrada en la portada |
| **JWT** | Token firmado que identifica la sesión de un usuario |
| **Lead** | Contacto interesado en una propiedad |
| **Migración** | Script versionado que modifica la estructura de la base de datos |
| **Monorepo** | Un solo repositorio con varias aplicaciones |
| **nginx** | Servidor web que recibe el tráfico y lo reparte a cada app |
| **PM2** | Administrador de procesos que mantiene las apps encendidas |
| **Portal** | Sitio web público |
| **PWA** | Aplicación web instalable en el celular |
| **R2** | Almacenamiento de archivos de Cloudflare |
| **Resend** | Servicio de envío de correos |
| **Seed** | Carga de datos iniciales |
| **SEO** | Optimización para buscadores |
| **Sidebar v2** | Variante de filtro con barra lateral en escritorio y panel en móvil |
| **Soft delete** | Borrado lógico: el registro se oculta pero no se elimina |
